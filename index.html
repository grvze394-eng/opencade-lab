Instrucciones para alumnos
  1. Pulsa Simular para iniciar el PLC.
  2. Activa brevemente X0 y desactívalo antes de llegar al final de carrera.
  3. El sensor X2 se activa al llegar al extremo y el segundo peldaño energiza Y1 para retraerlo.
  4. Modifica los contactos Ladder y comprueba el resultado.
  5. Prueba a eliminar un cable: el equipo conectado deja de funcionar.
  6. Guarda tu práctica en JSON para entregarla al profesor.
